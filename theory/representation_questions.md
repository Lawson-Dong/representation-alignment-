# Representation Questions

This repository is organized around two related questions about learned representations.

## 1. Model–brain correspondence

How does representational geometry change across the layers of a visual neural network, and to what extent does that geometry correspond to different stages of biological visual processing?

The current ResNet project approaches this question using Representational Similarity Analysis (RSA), comparing model-layer representations with Early Visual Cortex (EVC) and Inferotemporal Cortex (IT).

## 2. Semantic composition

How are multiple concepts combined inside a learned representation space?

The current CLIP project approaches this question using hybrid visual stimuli and tests whether a hybrid representation can be described in terms of the representations of its component concepts.

## Shared perspective

Both projects focus on internal representational structure rather than only task outputs. The goal is not to assume that artificial and biological systems implement identical computations, but to study measurable structure in their representation spaces and the relationships between those structures.

## Scope

These notes summarize the conceptual questions already described in the repository README. More formal definitions, equations, and experimental protocols can be added as the corresponding code and analyses are organized.
