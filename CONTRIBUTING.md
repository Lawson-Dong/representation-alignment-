# Contributing

For geometric dynamics experiments, run the offline checks described in `experiments/geometric_dynamics/README.md` before committing. Document checkpoint enums, cohort identities/order, preprocessing, pooling, seeds, software versions and execution status when changing a protocol. Keep generated activations, datasets and checkpoints outside Git. Include small result tables only with provenance and a clear distinction between measured results and proposed experiments.

Report bugs with the entrypoint, environment, traceback and minimal reproduction. Research changes should state the hypothesis, the controlled variables and the interpretation limits. Existing notebook outputs are historical records; put new runs in separately identified artifacts rather than silently replacing their evidence.
